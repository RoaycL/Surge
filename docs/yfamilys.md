# yfamilys 模块目录

来源：[Surge 页面](https://yfamilys.com/surge)。按 URL 去重，模块与面板共 421 个；不包含页面的两份完整配置。

模块保留原作者署名，添加来源标识和分类；外部脚本继续使用原链接。原文快照、SHA-256、脚本依赖及适配说明记录在 `upstreams/yfamilys/manifest.json`。

`Sync yfamilys Surge modules` 每 6 小时读取页面并同步全部模块；任一下载或适配失败即停止发布，保留上一次有效版本。也可在 Actions 手动运行。

融合版与同类单 App 模块请择一使用，避免重复的脚本标识和规则覆盖。

语法通过不代表第三方脚本仍可下载，也不代表各 App 功能已实测；账户、订阅、定位等参数须按模块说明自行填写。同一 App 的不同来源模块不要重复启用。
