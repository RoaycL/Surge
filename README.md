# Surge

自用 Surge 模块。

## 插件目录

收录 [RoaycL/fkikelee](https://github.com/RoaycL/fkikelee) 的 **275 个 Loon 插件转换版**，保留原作者署名。模块参数、依赖及兼容性差异见 [详细说明](Module/FKIKelee/README.md)。

- 点击名称获取模块地址；在 Surge「模块 → 从 URL 安装」中添加。
- 「导入」使用 Surge 官方 URL Scheme；若 GitHub 页面无法唤起 Surge，请复制名称对应的模块地址安装。
- 带参数的模块可在 Surge 内修改；同一 App 的不同版本请按需选择，避免同时启用。
- 哈啰单车缺失主体脚本，顺丰有一条上游响应截断，受限功能已在对应行标注。
